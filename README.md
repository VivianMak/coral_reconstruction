# 4D Dynamic Soft Coral Reconstruction with Light Fields

> This project is part of CREST Lab advised by Dr. Victoria Preston.


Coral reef ecosystems are deteriorating due to the effects of global warming on our oceans. And my goal with this resarch is to create a tool for scientists to characterize the effects of climate change in this underwater environment over time, by allowing them to see in places difficult for humans to exist in for longer periods of time. Current methods involve using satelite imagery and send human divers to ground truth these images of coral.

Ultimately coral reefs consist of hard and soft corals. When we think about remodeling hard corals, which are static, it feels pretty intuitive. However, with soft corals, there is a dynamic nature to them, with features that are elastic and could deform. Satelites and humans lack the qualitative abilities to observe soft corals in situ.

This is where the challenge comes in because many methods for reconstruction don’t actually account for moving objects in a scene. So what if there is actually a more clever way to utilize the existing research done in reconstruction by using a more information-rich sensor.

__How can we use a single light field camera to perform 4D dynamic reconstruction of soft corals?__
